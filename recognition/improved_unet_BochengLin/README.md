## 🧠 Project: Improved 3D U-Net for Prostate MRI Segmentation

This project implements a 3D improved U-Net architecture for prostate MRI segmentation.  
The model was trained and evaluated on the **HipMRI_Study_open dataset**, using PyTorch with CUDA acceleration.

### **Environment Setup**

To reproduce this project, create the environment using:

```bash
conda env create -f improved_unet_BochengLin/environment.yml
conda activate unet3d
